# A Corrida do Prompt

## Descrição do Projeto
Este projeto analisa o impacto direto das instruções estruturadas na capacidade criativa e interpretativa da Inteligência Artificial Qwen3.5-Plus. O objetivo foi mitigar a aleatoriedade dos modelos gerativos através de restrições de contexto histórico e literário.

## Tecnologias Utilizadas
* ***Plataforma:*** Qwen.ai
* ***Modelo de IA:*** Qwen3.5-Plus
* ***Técnicas Aplicadas:*** Roleplay Avançado, Restrição de Estilo Artístico, Engenharia de Prompt Literária.

## Resultados e Aprendizados
O experimento dividiu-se em duas frentes de execução:
1. **Projeto 1 - Imagem do Astronauta:** O modelo atuou sob a persona do pintor Diego Velázquez. Utilizando referências técnicas do movimento barroco do século 17, o prompt aplicou o conceito de *chiaroscuro* para gerar contraste dramático entre luz e sombra, forçando o algoritmo a ignorar padrões de fotorrealismo modernos para recriar um astronauta a tocar violoncelo em Marte.
2. **Projeto 2 - Carta do Pirata:** Criação de uma correspondência formal e dramática do capitão pirata Edward New Gate endereçada ao Rei Solomon Vortigger. A IA conseguiu exteriorizar sentimentos profundos de isolamento e vazio existencial causados por crimes passados, gerando um texto onde a riqueza roubada revelou-se cinza diante do remorso.
