# IA no Desenvolvimento de Software - Análise Crítica

## Descrição do Projeto
Este projeto desenvolve um estudo qualitativo sobre a transformação do papel do engenheiro de software no cenário atual de desenvolvimento assistido por inteligência artificial. Foram mapeados os riscos técnicos, as barreiras éticas e os novos diferenciais do mercado profissional.

## Tecnologias Utilizadas
* ***Plataforma de Análise:*** AI Studio
* ***Modelagem Teórica:*** Engenharia Reversa, Padrões de Projeto (Design Patterns) e Princípios SOLID.

## Resultados e Aprendizados
* ***O Efeito Caixa Preta:** A automação transfere o esforço da escrita manual de código para a descrição abstrata de regras lógicas. O grande risco reside na dependência gerada em programadores juniores, que conseguem criar softwares funcionais, mas carecem da base necessária para depurar falhas complexas ou vazamentos de memória.
* ***Fronteira Ética e Deepfake de Software:*** A engenharia reversa atinge seu ponto de rutura ética e converte-se em plágio quando é utilizada para replicar a interface e os fluxos de concorrentes com o propósito de substituição comercial direta, sem adicionar inovação arquitetural ou valor de engenharia próprio.
* ***O Novo Diferencial Técnico:*** A habilidade de codificar sintaxe bruta perde centralidade para o Pensamento Sistémico, para a Engenharia de Requisitos e para os processos criteriosos de Code Review.
